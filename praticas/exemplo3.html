1. O que é JavaScript?

HTML descreve o conteúdo, CSS cuida da aparência e JavaScript permite responder a ações. Por exemplo, ao clicar em um botão, um script pode atualizar um número sem recarregar a página.

2. Variáveis: guardar informações

let cliques = 0;
const limite = 10;
  • let cria uma variável que pode receber outro valor. O contador usa let porque seu valor muda.
  • const cria uma referência que não será reatribuída. Use quando não precisa trocar o valor.
  • cliques e limite são nomes escolhidos por quem escreve o código.
  • O número 0 é um dado numérico; textos ficam entre aspas, como "Olá!".

3. Funções: organizar ações

Uma função reúne instruções com um nome. Ela só executa quando é chamada:

function aumentarContador() {
    cliques = cliques + 1;
    atualizarPagina();
}

A expressão cliques = cliques + 1 soma um ao valor atual e guarda o resultado de volta na variável.

4. Encontrar e atualizar elementos

const numero = document.getElementById("contador");
numero.textContent = cliques;
  • document representa a página que o navegador carregou.
  • getElementById("contador") encontra o elemento que tem id="contador" no HTML.
  • textContent lê ou muda o texto que aparece dentro do elemento.

5. Eventos: responder a cliques

botao.addEventListener("click", aumentarContador);

addEventListener escuta um evento. Neste caso, quando acontece um "click", o navegador chama a função aumentarContador. Não usamos parênteses depois do nome da função porque queremos que ela rode quando houver o clique, não imediatamente.

O código JavaScript completo do exemplo

Este trecho conecta os botões ao contador e atualiza o número e a mensagem:

let cliques = 0;

const numero = document.getElementById("contador");
const mensagem = document.getElementById("mensagem");
const botaoAumentar = document.getElementById("aumentar");
const botaoZerar = document.getElementById("zerar");

function atualizarPagina() {
    numero.textContent = cliques;
    if (cliques === 0) {
        mensagem.textContent = "Você ainda não clicou no botão.";
    } else if (cliques === 1) {
        mensagem.textContent = "Você clicou 1 vez.";
    } else {
        mensagem.textContent = `Você clicou ${cliques} vezes.`;
    }
}

function aumentarContador() {
    cliques = cliques + 1;
    atualizarPagina();
}

function zerarContador() {
    cliques = 0;
    atualizarPagina();
}

botaoAumentar.addEventListener("click", aumentarContador);
botaoZerar.addEventListener("click", zerarContador);

=== compara se dois valores são iguais. A estrutura if/else escolhe uma mensagem para zero, uma ou várias vezes. O texto entre crases permite inserir uma variável usando ${...}.

6. Onde colocar o JavaScript

O exemplo deste arquivo usa uma tag <script> no final do <body>. Assim, o HTML dos botões já existe quando o JavaScript procura por eles.

<script>
    // O código JavaScript fica aqui.
</script>
</body>

Em projetos maiores, é comum salvar o JavaScript em outro arquivo, por exemplo script.js, e carregá-lo com <script src="script.js" defer></script> dentro do <head>. O atributo defer faz o navegador esperar o HTML ser lido antes de executar o arquivo.

7. JavaScript para alternar o tema

O botão no topo de cada página alterna entre tema claro e escuro. JavaScript adiciona ou remove a classe dark-theme do body; o CSS define as cores para cada tema. As regras CSS de responsividade continuam cuidando do tamanho das telas.

botaoTema.addEventListener("click", function () {
    const temaEscuroAtivo = document.body.classList.toggle("dark-theme");
    botaoTema.textContent = temaEscuroAtivo
        ? "Ativar tema claro"
        : "Ativar tema escuro";
});

Como experimentar

  1. Abra este arquivo em um editor, como o VS Code.
  2. Encontre function aumentarContador() perto do final do arquivo.
  3. Experimente mudar cliques + 1 para cliques + 2.
  4. Salve e atualize a página no navegador. Cada clique agora deve aumentar o contador em 2.

Dica: se o botão não funcionar, confira se os valores de id no HTML correspondem aos nomes usados em getElementById, e veja se há erros no console do navegador.
