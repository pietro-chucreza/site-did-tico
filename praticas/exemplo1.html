Aprendendo HTML e CSS

Veja como o HTML organiza o conteúdo e como o CSS muda sua aparência.

1. O resultado na página

Este cartão foi criado com HTML e ganhou cores e espaçamento com CSS:

Meu primeiro cartão

Este texto está dentro de um cartão feito com HTML e CSS.

2. O código HTML

HTML cria os elementos: o título usa <h3> e o texto usa <p>.

<div class="preview">
    <h3>Meu primeiro cartão</h3>
    <p>Este texto está dentro de um cartão feito com HTML e CSS.</p>
</div>

As tags aparecem como texto porque usamos &lt; e &gt; no código desta página. Assim, o navegador mostra os sinais < e > em vez de interpretar o trecho como HTML.

3. O código CSS

CSS escolhe os elementos pela classe .preview e define como eles devem aparecer:

.preview {
    padding: 18px;
    background: #f5f0e6;
    border-left: 4px solid #c58b4b;
    border-radius: 6px;
}

Como fazer no seu arquivo

  1. Coloque a estrutura e o conteúdo dentro de <body>.
  2. Adicione regras CSS dentro de <style>, que fica no <head>.
  3. No HTML, use class="preview". No CSS, escreva .preview para aplicar o estilo.
  4. Salve o arquivo com a extensão .html e abra-o no navegador para ver o resultado.
