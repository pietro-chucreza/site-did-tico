Aprendendo CSS

CSS define a aparência de uma página: cores, tamanhos, espaços e como os elementos se organizam.

O resultado

O cartão abaixo é HTML com estilos aplicados por CSS:

Um cartão estilizado

O fundo, a borda, o espaço interno e a sombra foram definidos com CSS.

1. A estrutura de uma regra CSS

Uma regra CSS tem um seletor e um bloco entre chaves. Dentro dele ficam as declarações:

.cartao {
    background: #f5f0e6;
    padding: 20px;
}
  • .cartao é o seletor: escolhe os elementos que têm class="cartao".
  • background e padding são propriedades: dizem o que será alterado.
  • #f5f0e6 e 20px são valores: dizem como cada propriedade será aplicada.
  • Os dois-pontos : separam propriedade e valor; o ponto e vírgula ; encerra cada declaração.

2. Seletores: como escolher o que estilizar

O seletor informa ao navegador quais elementos recebem os estilos.

p {
    color: #263238;
}

.cartao {
    background: #f5f0e6;
}

#aviso {
    color: #a45b2a;
}
  • p seleciona todos os parágrafos.
  • .cartao seleciona elementos com a classe cartao. No HTML, classes são escritas com class="cartao"; no CSS, começam com ponto.
  • #aviso seleciona o elemento cujo identificador é id="aviso". No CSS, IDs começam com cerquilha.
  • .cartao h3 seleciona apenas os títulos h3 que estão dentro de um elemento da classe cartao.

3. Propriedades comuns

.cartao {
    color: #263238;
    background: #f5f0e6;
    padding: 20px;
    margin: 16px 0;
    border: 1px solid #d5e1de;
    border-radius: 6px;
}
  • color muda a cor do texto; background muda o fundo.
  • padding cria espaço dentro da borda, entre o conteúdo e a borda.
  • margin cria espaço fora da borda, separando o elemento dos outros.
  • border desenha a borda e define sua espessura, estilo e cor.
  • border-radius arredonda os cantos.
  • box-shadow adiciona sombra; use com moderação para destacar um elemento.

4. Cores e medidas

  • Cores podem ser escritas em hexadecimal, como #245653, ou com nomes, como white.
  • px representa pixels e serve para medidas precisas, como uma borda de 1px.
  • rem é relativo ao tamanho de texto padrão do navegador; é útil para fontes e espaçamentos que acompanham a preferência da pessoa.
  • % representa uma proporção do espaço disponível.
  • rgba(38, 50, 56, 0.12) define uma cor com transparência: o último número vai de 0 (transparente) a 1 (opaco).

5. Como o CSS chega ao HTML

Neste arquivo, o CSS está dentro da tag <style>, que fica no <head>. O navegador lê essas regras e as aplica aos elementos do <body>.

<article class="cartao">
    <h3>Um cartão estilizado</h3>
    <p>Um texto dentro do cartão.</p>
</article>

A classe cartao conecta esse HTML à regra CSS .cartao. Você pode reutilizar uma classe em vários elementos.

6. Responsividade

Uma media query permite mudar os estilos conforme o tamanho da tela. Aqui, o espaçamento diminui em telas estreitas:

@media (max-width: 520px) {
    body {
        padding: 20px 12px;
    }
}

O trecho só é aplicado quando a largura da tela é de até 520px. Isso ajuda a página a ficar confortável em celulares.

Como experimentar

  1. Abra este arquivo em um editor de texto ou no VS Code.
  2. Encontre .cartao dentro da tag <style>.
  3. Altere um valor, por exemplo, troque background: #f5f0e6 por background: #e2eeee.
  4. Salve o arquivo e atualize a página no navegador para ver a mudança.

Dica: se uma regra não aparecer, confira se o nome da classe no HTML (sem ponto) combina com o seletor no CSS (com ponto), e se as chaves e os pontos e vírgulas estão no lugar.
